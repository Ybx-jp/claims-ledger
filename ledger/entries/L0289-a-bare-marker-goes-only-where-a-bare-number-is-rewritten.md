## Assertion

A lift writes a marker without the slug only into an artifact the document globs select, whatever the slug setting says about that path.

## Scope

metric: the spelling of the id in the marker a lift writes
cohort: the markers a lift writes
condition: the artifact the ground names is, or is not, selected by the document globs

## Warrant

A renumber rewrites a whole id in any file it finds one in, and a bare number only where the package knows a number is read as an id: the entries and the configured documents. A marker written without the slug anywhere else would therefore stop following its entry through a renumber and afterwards name a different entry or none — in a file no checker reads, so nothing would report it. The boundary that decides it is the one reference_row already asks, whether the artifact is a document, asked here of the spelling rather than of the References row; asking it twice through the same membership test is what keeps the marker a lift leaves and the row it owes from disagreeing about what a document is. Three entries rest on this same section and are different claims about it, so each is distinguished rather than left to be read as the same commitment: L0277 says a marker is written at all, L0278 says where it is declared, L0288 says no rule keys off the spelling, and this one says where each spelling may go.
