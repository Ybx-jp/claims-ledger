# Nimbus operator handbook

This documentation repository publishes a checked description of the review boundary
(D0001-review-boundary-is-inclusive, cites-as-live) and the operator response
(D0002-review-response-is-documented, cites-as-live).

Its ledger treats the UI behavior, backend OpenAPI file, and research summary as
registered snapshots from other repositories, rather than pretending local entry IDs
resolve across repository roots.
