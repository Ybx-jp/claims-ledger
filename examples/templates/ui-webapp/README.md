# Nimbus Console

This deliberately small TypeScript UI renders an evidence-risk banner. The checked
claim is that the implementation and backend agree on the threshold
(U0001-ui-banner-uses-service-threshold, cites-as-live).

The backend contract and research summary under `evidence/` are exact, registered
snapshots from the other generated repositories; `examples/materialize.py` verifies the
copies before reporting success.
