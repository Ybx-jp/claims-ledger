# Fixture lab note 005 — mean aggregation makes it a fraction, not a count

**Date:** 2026-09-02 · **Status:** fixture. A synthetic lab note for the red-team corpus;
its numbers were typed, not measured.

## Observation

Star graphs, one SAGEConv layer, 16-dim, eval mode, untrained weights, uniform
perturbation 0.1 on a uniform-random stale set.

| degree | stale fraction | centre L2 error |
|---|---|---|
| 8 | 0.25 | 0.031 |
| 64 | 0.25 | 0.031 |
| 512 | 0.25 | 0.031 |
| 64 | 0.50 | 0.062 |

At fixed fraction the error is degree-invariant to three decimals; at fixed count it
falls as 1/deg.

## Interpretation

Mean aggregation weights each neighbour by 1/deg, so a fixed perturbation on a fraction
f of neighbours contributes f times the per-neighbour effect regardless of degree.
